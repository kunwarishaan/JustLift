# Just Lift

A two-player local push-up web app built with Vite and React in plain JavaScript.

Step 1 contains only the scaffold and a placeholder heading. Camera access, pose
detection, rep counting, form ratings, and scoring will come in later steps.

## Development

Use Node.js 22.12+ (Node.js 22.20.0 was used for setup).

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production build is written to `dist/`.
